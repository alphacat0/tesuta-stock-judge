## 📖 概要

このスキルは、テスタさんの取引哲学を AI エージェントに「レンズ」として適用させ、ティッカーやチャートに対して**構造化された判断**を生成します。

主な特徴：

- **短期は需給読み**（スキャル/デイトレ）、**中長期は材料・業績駆動**の二刀流
- **リスクファースト**：エントリー前に必ず損切りラインを定義、「コツコツドカン」を回避
- **高エッジのみ参加**：「勝てる場所だけ参加する」、エッジ不明瞭なら見送り
- **資金量×流動性でサイジング**を考慮
- **ハルシネーション対策**：未確認の数値を捏造せず、データの出所（ユーザー提供／Web検索／未観測）を必ず明示
- **矛盾解決ルール**：チャート画像と口頭情報が食い違う場合、実観測データを優先

## 🚀 インストール

実際の指示は `SKILL.md`（本体）に集約されており、各エージェントはそれを読み込んで動作します。**Claude 以外のツールでも使えます。**

| ツール | 読み込むファイル | 配置/利用方法 |
|--------|----------------|--------------|
| **Claude Code** | `SKILL.md`（自動認識） | スキルディレクトリに配置 |
| **Codex** | `SKILL.md`（スキルとして認識）<br>または `AGENTS.md`（プロジェクト指示として） | ① `~/.codex/skills/tesuta-stock-judge/` に配置（推奨。全プロジェクトで `/tesuta-stock-judge` または「テスタ」というキーワードで呼出可能）<br>② プロジェクト直下に clone して `AGENTS.md` 経由で利用 |
| その他（AGENTS.md対応） | `AGENTS.md` → `SKILL.md` | リポジトリ直下に置けば自動で読み込み |

> 🧩 **設計**：原則・手順・出力フォーマットは `SKILL.md` 一箇所（信頼できる唯一の情報源）にだけ書かれています。`AGENTS.md` は数行の「入口」で、`SKILL.md` を読むよう各エージェントに指示します。これにより、原則を更新するときは `SKILL.md` を直すだけで全ツールに反映されます。

### Claude Code の場合

```bash
# 個人用（全プロジェクトで使用可能）
git clone https://github.com/alphacat0/tesuta-stock-judge.git \
  ~/.claude/skills/tesuta-stock-judge

# または特定プロジェクト用
git clone https://github.com/alphacat0/tesuta-stock-judge.git \
  .claude/skills/tesuta-stock-judge
```

配置後、Claude Code を起動すると `tesuta-stock-judge` スキルが自動的に認識されます。動作確認は「利用可能なスキルを教えて」と尋ね、一覧に出れば成功です。

### Codex の場合（スキルとしてインストール＝推奨）

Codex では `SKILL.md` の YAML frontmatter（`name` / `description`）を読み取り、スキル一覧に登録します。`~/.codex/skills/` 以下に配置することで、**全プロジェクトから** `/tesuta-stock-judge` または「テスタ」「株判断」といったキーワードで呼び出せるようになります。

```bash
git clone https://github.com/alphacat0/tesuta-stock-judge.git   ~/.codex/skills/tesuta-stock-judge
```

配置後、Codex を再起動すると、利用可能スキル一覧に `tesuta-stock-judge: テスタ（@tesuta001）の取引原則に基づく株式判断...` が表示されます。

> 💡 Codex には `skill-installer` スキルもあり、`skill-installer` 経由で GitHub からインストールすることも可能です。また、`SKILL.md` の frontmatter 内 `name` / `description` がスキル一覧での表示名・説明として使われます。

### Codex の場合（プロジェクト直配置＝簡易版。上記スキルインストールが推奨）

リポジトリを clone し、その中で Codex を起動するだけです。起動時に `AGENTS.md` を自動で読み込み、そこから `SKILL.md` の指示に従います。`AGENTS.md` に対応した他のエージェントでも同様に利用できます。

```bash
git clone https://github.com/alphacat0/tesuta-stock-judge.git
cd tesuta-stock-judge
# このディレクトリで codex を起動
```

別プロジェクト内で使いたい場合は、`AGENTS.md`・`SKILL.md`・`references/` をそのプロジェクトに配置するか、`AGENTS.md` から本リポジトリのパスを参照させてください。

### Cowork（デスクトップアプリ）の場合

`SKILL.md` と `references/` を含むフォルダを、スキルディレクトリに配置します。詳細は [Claude のスキル公式ドキュメント](https://docs.claude.com) を参照してください。

### ツールの読み替えについて

`SKILL.md` 内で言及される `WebSearch` は Claude のツール名です。Codex など他のエージェントでは、**各自の Web 検索 / fetch ツールに自動的に読み替えられます**（`AGENTS.md` にその指示を明記済み）。Web 検索ツールが無い環境では、価格や出来高を捏造せず、ユーザーにデータ提供を求める挙動になります。

## 💡 使い方

### 1. もっとも簡単な使い方

銘柄名（または銘柄コード）を伝えるだけで起動します。呼び出し方はツールによって異なります：

**Claude Code** — `/tesuta-stock-judge` で明示的に呼び出す：
```
/tesuta-stock-judge キオクシア（285A）をデイトレ目線で判断して。資金は1000万円。
```

**Codex（スキルインストール済み・推奨）** — `/tesuta-stock-judge` で明示的に呼び出す：
```
/tesuta-stock-judge キオクシア（285A）をデイトレ目線で判断して
```

**Codex（プロジェクト直配置）** — 「テスタ」を含む自然な指示で自動認識：
```
テスタの手法でエヌビディアを見て
```

> 💡 **`/tesuta-stock-judge` を付けるのが最も確実です。** 付けなくても「テスタ」「株判断」といったキーワードでスキルがマッチすることがありますが、`/skill-name` で明示すれば誤検出を防げます。

以下は全ツール共通の入力例です：

```
キオクシア（285A）をデイトレ目線で判断して
```
この場合、エージェントは不足情報を Web 検索で補い、足りない前提（資金規模など）は逆に質問してきます。**全部を一度に揃える必要はありません。**

### 2. 詳しく判断させる使い方（推奨）

入力が具体的なほど、判断精度が上がります。以下を添えると効果的です。

| 項目 | 例 | 効果 |
|------|-----|------|
| **銘柄** | キオクシア（285A） | 必須 |
| **タイムフレーム** | デイトレ／スイング／中長期 | 戦い方の軸が決まる |
| **資金規模** | 資金は300万円 | サイジングの核心変数 |
| **盤面（板・歩み値）** | 買い板厚め、成行買い連続 | 短期需給判断の質が上がる |
| **価格・出来高** | 前日比+5%、出来高は平常の3倍 | 文脈の精度向上 |
| **材料・スタイル** | AI向けNAND需要、自分は技術7:基本面3 | 文脈の補強 |

**理想的な入力例：**

```
キオクシア（285A）をデイトレ目線で判断して。
資金は300万円。今の板は買い板厚め、歩み値で成行買いが連続。
前日比+5%、出来高は平常の3倍くらい。
```

### 3. チャート画像（スクリーンショット）を使う使い方

**このスキルの最も強力な使い方です。** 証券アプリや TradingView のチャートのスクリーンショットを添付すると、エージェントが**実際のローソク足・出来高・価格を直接読み取って**判断します。

> ⚠️ **画像入力に対応したエージェントが必要です**（Claude など）。画像を扱えないツールの場合は、チャートの数値（OHLC・出来高）をテキストで伝えてください。

#### 手順

1. 証券アプリ／TradingView などで対象銘柄のチャートを開く
2. **OHLC（始値・高値・安値・終値）と出来高の数値が読める状態**でスクリーンショットを撮る
3. エージェントのチャット欄に画像を添付（ドラッグ＆ドロップ／ペーストなど、ツールの方法に従う）
4. 次のように指示する：

```
（チャート画像を添付して）
このチャートをテスタの手法で分析して。デイトレ目線で。資金は300万円。
```

**添付するチャート画像の例：**

![キオクシア（285A）日足チャートの添付例](examples/kioxia_example.png)

> このような OHLC・出来高が読めるチャートを添付すると、エージェントがローソク足を直接解析して判断します。上の画像に対する実際の出力は [`examples/kioxia-daily-analysis.md`](examples/kioxia-daily-analysis.md) を参照してください。

#### スクリーンショットのコツ

- **時間軸を明記**：日足／5分足など、チャートのタイムフレームが分かるようにする（エージェントは日足の方向と日中の板を分けて評価します）
- **数値が見える状態で**：上部のOHLC・出来高表示が写っていると精度が上がります
- **板情報は別途テキストで**：板・歩み値はチャート画像に写らないため、リアルタイムの板状況はテキストで補足するか、「板は未観測でOK」と伝えてください
- **複数時間軸も可**：日足＋5分足など複数枚を添付すると、マルチタイムフレーム分析になります

> 💡 **矛盾はチャート優先**：もしテキストで「+5%・買い板厚め」と書いても、添付チャートが大陰線なら、エージェントはチャート（実観測データ）を正として判断し、矛盾を明示します。

## 📊 出力フォーマット

このスキルは常に以下の構造で回答します。

```
【ティッカー / コンテキスト要約】   ← 銘柄・現在価格（出所明示）・値動き・出来高・材料
【推奨タイムフレーム】 ＋ 根拠
【ポジションサイズのガイダンス】     ← 流動性・単元×資金規模の整合への言及を含む
【需給分析 または 材料・テーゼ分析】 ← 判定＋証拠（観測元を明示）
【エッジ評価】 High / Medium / Low ＋ 根拠
【エントリートリガー / ゾーン】
【ストップロス / 無効化レベル】
【主要リスク・監視ポイント】
【心理・規律リマインダー】
【適応注記】                         ← 手法の「混雑」度合い
【免責】
```

実際の出力サンプルは [`examples/kioxia-daily-analysis.md`](examples/kioxia-daily-analysis.md) を参照してください。

## 🧠 設計上のこだわり

このスキルは「それっぽい結論を出す」ことより、**正直さと再現性**を優先しています。

- **データ取得が先**：判断の前に必ず現在情報を取得。記憶だけで価格や出来高を語りません。
- **捏造しない**：確認していない数値（株価・板の厚さ・移動平均など）はでっち上げず、「未確認」「要確認」と明示します。
- **出所を明示**：すべての根拠に観測元（ユーザー提供／Web検索／未観測）を付けます。
- **見送る勇気**：エッジが不明瞭なら、無理に「買い」「売り」を出さず「見送り」を推奨します。
